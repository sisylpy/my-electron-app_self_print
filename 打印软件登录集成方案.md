# 🔐 打印软件登录集成方案

## ✅ 需求确认

### **登录流程：**
```
打印软件启动
  ↓
输入手机号
  ↓
验证手机号（管理员身份）
  ↓
自动获取所属市场信息
  ↓
显示该市场的设备列表
  ↓
选择打印机设备
  ↓
缓存配置
  ↓
开始打印
```

## 🔑 登录接口

### **接口1：打印软件登录（核心）** ⭐

**接口地址：**
```
POST /api/machine/printSoftware/login
```

**请求参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | ✅ | 手机号（11位） |

**请求示例：**
```http
POST /nongxinle/api/machine/printSoftware/login
Content-Type: application/x-www-form-urlencoded

phone=13800138000
```

**返回示例（成功）：**
```json
{
  "code": 0,
  "msg": "success",
  "managerId": 1,
  "managerName": "张三",
  "phone": "13800138000",
  "marketId": 1,
  "marketName": "北京新发地批发市场"
}
```

**返回示例（失败）：**
```json
{
  "code": 500,
  "msg": "手机号未注册，请联系系统管理员"
}
```

## 💻 完整集成代码

### **Java示例（完整版）：**

```java
import java.io.*;
import java.net.*;
import java.nio.charset.StandardCharsets;
import java.util.Properties;
import org.json.JSONObject;

public class PrintSoftwareWithLogin {
    
    private String apiBaseUrl;
    private Integer managerId;
    private String managerName;
    private String phone;
    private Integer marketId;
    private String marketName;
    private Integer deviceId;
    private String deviceName;
    
    private final String CONFIG_FILE = "printer_config.properties";
    
    /**
     * 打印软件启动
     */
    public void startup() {
        try {
            // 尝试加载配置
            if (loadConfig()) {
                // 配置存在，验证有效性
                if (validateConfig()) {
                    System.out.println("配置有效，直接进入主界面");
                    showMainWindow();
                } else {
                    System.out.println("配置无效，需要重新登录");
                    showLoginDialog();
                }
            } else {
                // 配置不存在，显示登录界面
                System.out.println("首次使用，显示登录界面");
                showLoginDialog();
            }
        } catch (Exception e) {
            e.printStackTrace();
            showLoginDialog();
        }
    }
    
    /**
     * 登录
     * @param phone 手机号
     * @return 登录是否成功
     */
    public boolean login(String phone) {
        try {
            String url = apiBaseUrl + "/api/machine/printSoftware/login";
            String params = "phone=" + URLEncoder.encode(phone, "UTF-8");
            
            HttpURLConnection conn = (HttpURLConnection) new URL(url).openConnection();
            conn.setRequestMethod("POST");
            conn.setRequestProperty("Content-Type", "application/x-www-form-urlencoded");
            conn.setDoOutput(true);
            
            // 发送请求
            conn.getOutputStream().write(params.getBytes(StandardCharsets.UTF_8));
            
            // 读取响应
            if (conn.getResponseCode() == 200) {
                BufferedReader br = new BufferedReader(
                    new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8)
                );
                StringBuilder response = new StringBuilder();
                String line;
                while ((line = br.readLine()) != null) {
                    response.append(line);
                }
                br.close();
                
                // 解析JSON
                JSONObject json = new JSONObject(response.toString());
                
                if (json.getInt("code") == 0) {
                    // 登录成功，保存信息
                    this.managerId = json.getInt("managerId");
                    this.managerName = json.getString("managerName");
                    this.phone = json.getString("phone");
                    this.marketId = json.getInt("marketId");
                    this.marketName = json.getString("marketName");
                    
                    System.out.println("✅ 登录成功！");
                    System.out.println("管理员：" + managerName);
                    System.out.println("市场：" + marketName);
                    
                    // 获取设备列表
                    showDeviceSelectDialog();
                    
                    return true;
                } else {
                    System.err.println("❌ 登录失败：" + json.getString("msg"));
                    return false;
                }
            }
            
            return false;
            
        } catch (Exception e) {
            System.err.println("登录异常：" + e.getMessage());
            e.printStackTrace();
            return false;
        }
    }
    
    /**
     * 获取设备列表并选择设备
     */
    private void showDeviceSelectDialog() {
        try {
            String url = apiBaseUrl + "/api/machine/printSoftware/devices?marketId=" + marketId;
            
            HttpURLConnection conn = (HttpURLConnection) new URL(url).openConnection();
            conn.setRequestMethod("GET");
            
            if (conn.getResponseCode() == 200) {
                BufferedReader br = new BufferedReader(
                    new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8)
                );
                StringBuilder response = new StringBuilder();
                String line;
                while ((line = br.readLine()) != null) {
                    response.append(line);
                }
                br.close();
                
                // 解析设备列表
                JSONObject json = new JSONObject(response.toString());
                
                if (json.getInt("code") == 0) {
                    // 显示设备选择界面
                    // TODO: 显示设备列表让用户选择
                    System.out.println("设备列表：" + json.getJSONArray("list"));
                }
            }
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
    
    /**
     * 选择设备后保存配置
     */
    public void selectDevice(int deviceId, String deviceName) {
        this.deviceId = deviceId;
        this.deviceName = deviceName;
        
        // 保存配置
        saveConfig();
        
        System.out.println("✅ 配置保存成功");
        System.out.println("市场：" + marketName + " (ID:" + marketId + ")");
        System.out.println("设备：" + deviceName + " (ID:" + deviceId + ")");
        
        // 进入主界面
        showMainWindow();
    }
    
    /**
     * 保存配置
     */
    private void saveConfig() {
        try {
            Properties props = new Properties();
            props.setProperty("api.base.url", apiBaseUrl);
            props.setProperty("manager.id", String.valueOf(managerId));
            props.setProperty("manager.name", managerName);
            props.setProperty("phone", phone);
            props.setProperty("market.id", String.valueOf(marketId));
            props.setProperty("market.name", marketName);
            props.setProperty("device.id", String.valueOf(deviceId));
            props.setProperty("device.name", deviceName);
            
            props.store(new FileOutputStream(CONFIG_FILE), "打印软件配置");
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    /**
     * 加载配置
     */
    private boolean loadConfig() {
        try {
            File file = new File(CONFIG_FILE);
            if (!file.exists()) {
                return false;
            }
            
            Properties props = new Properties();
            props.load(new FileInputStream(CONFIG_FILE));
            
            this.apiBaseUrl = props.getProperty("api.base.url");
            this.managerId = Integer.parseInt(props.getProperty("manager.id", "0"));
            this.managerName = props.getProperty("manager.name");
            this.phone = props.getProperty("phone");
            this.marketId = Integer.parseInt(props.getProperty("market.id", "0"));
            this.marketName = props.getProperty("market.name");
            this.deviceId = Integer.parseInt(props.getProperty("device.id", "0"));
            this.deviceName = props.getProperty("device.name");
            
            return marketId > 0 && deviceId > 0;
            
        } catch (Exception e) {
            return false;
        }
    }
    
    /**
     * 验证配置有效性
     */
    private boolean validateConfig() {
        // 简单验证
        return managerId != null && managerId > 0 
            && marketId != null && marketId > 0
            && deviceId != null && deviceId > 0;
    }
    
    /**
     * 显示登录对话框（示意）
     */
    private void showLoginDialog() {
        System.out.println("=== 打印软件登录 ===");
        System.out.println("请输入手机号：");
        // TODO: 显示登录界面
    }
    
    /**
     * 显示主窗口（示意）
     */
    private void showMainWindow() {
        System.out.println("=== 打印软件主界面 ===");
        System.out.println("当前市场：" + marketName);
        System.out.println("当前设备：" + deviceName);
        // TODO: 显示主界面
    }
}
```

## 🔒 安全性设计

### **1. 手机号验证**

```java
// 验证手机号格式
public boolean validatePhone(String phone) {
    if (phone == null || phone.trim().isEmpty()) {
        return false;
    }
    
    // 中国大陆手机号正则
    String regex = "^1[3-9]\\d{9}$";
    return phone.matches(regex);
}
```

### **2. 账号状态检查**

后端接口会自动检查：
- ✅ 手机号是否存在
- ✅ 账号是否被禁用
- ✅ 市场是否存在

### **3. 登录有效期（可选）**

```java
// 在配置中保存登录时间
props.setProperty("login.time", String.valueOf(System.currentTimeMillis()));

// 加载时检查是否过期（例如7天）
long loginTime = Long.parseLong(props.getProperty("login.time", "0"));
long now = System.currentTimeMillis();
long days = (now - loginTime) / (1000 * 60 * 60 * 24);

if (days > 7) {
    System.out.println("登录已过期，请重新登录");
    showLoginDialog();
}
```
