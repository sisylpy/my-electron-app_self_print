# customer 模块边界

客户中心现在是 ProductShell 下的独立业务模块，负责客户全生命周期资料，不再复用 `Bills.vue` 的今日订单工作区。

- 客户基础资料、配送设置和标签通过右侧抽屉维护；
- 客户商品支持专属文字、图片要求和商品关系维护；
- 客户商品默认按已完成历史订单的订货频率分组，也可切换为按订货金额查看；金额视图默认近 90 天，并支持近 30 天、近一年和全部；
- 两种视图都显示平均每次订货量：频率视图固定使用近 90 天，金额视图跟随所选时间范围；只平均与客户商品当前订货单位一致的已完成历史订单；
- 商品行最终列顺序为商品信息、金额或主频率、订货习惯、上次订货、操作；金额视图的订货习惯列同时显示平均每次订货量和近 90 天订货频率，频率视图在该列只显示平均每次订货量；
- 操作区保留“商品要求”“订货单价”“历史单价”三个入口：“订货单价”维护客户商品关系上的默认订货价，“历史单价”只读取已完成历史订单的成交记录，两者不能互相替代；
- 金额视图按客户全部商品的累计订货额贡献分为核心（前 70%）、重要（70%–90%）、一般（其余）和无订货额；搜索只过滤显示，不重新计算档次；
- 售后问题始终按父客户（整家门店）汇总；
- AI 预计订单按门店内部订货部门分别展示，并允许直接订货；
- 历史订单保留查询、详情和 Excel 下载能力；
- 今日新订单仍统一进入订单工作台处理。

变更历史见 [客户中心变更日志](./docs/customer-center-change-log.md)。
