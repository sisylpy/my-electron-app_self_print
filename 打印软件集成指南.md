# 🖨️ 自助打印软件集成指南

## 📋 文档说明

本文档面向打印软件开发人员，说明如何将打印软件与自助打印统计系统对接。

---

## 🎯 集成流程概述

```
1. 获取市场列表
   ↓
2. 用户选择市场
   ↓
3. 获取该市场的打印机设备列表
   ↓
4. 用户选择打印机设备
   ↓
5. 缓存设备信息到本地（市场ID + 设备ID）
   ↓
6. 打印票据时，调用记录接口（带上设备信息）
   ↓
7. 系统自动：记录打印 + 扣减纸张 + 检查提醒
```

---

## 🔧 技术对接方案

### **方案A：标准HTTP接口对接（推荐）** ⭐

适用于：独立的打印软件、桌面应用、Web应用

```
打印软件 → HTTP请求 → 后端API → 记录打印 + 扣纸
```

### **方案B：SDK集成**

适用于：Java开发的打印软件

```
打印软件 → 引入Jar包 → 直接调用Service → 记录打印
```

### **第四步：打印并记录**

#### **核心接口：记录打印**

**接口地址：**
```
POST /nongxinle/api/machine/print/record
```

**请求参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| billId | Integer | ✅ | 单据ID（必须） |
| deviceId | Integer | ✅ | 打印机设备ID（从缓存读取） |
| marketId | Integer | ✅ | 市场ID（从缓存读取） |
| distributerId | Integer | ✅ | 配送商ID |
| billTotal | Double | ❌ | 单据金额（可选） |
| billTradeNo | String | ❌ | 单据流水号（可选） |
| operatorId | Integer | ❌ | 操作人ID（可选） |
| operatorName | String | ❌ | 操作人姓名（可选） |

**请求示例（form表单）：**
```http
POST /nongxinle/api/machine/print/record HTTP/1.1
Host: yourdomain.com
Content-Type: application/x-www-form-urlencoded

billId=1001&deviceId=1&marketId=1&distributerId=5&billTotal=158.50&billTradeNo=BL202410150001
```

**请求示例（JSON）：**
```http
POST /nongxinle/api/machine/print/record HTTP/1.1
Host: yourdomain.com
Content-Type: application/json

{
  "billId": 1001,
  "deviceId": 1,
  "marketId": 1,
  "distributerId": 5,
  "billTotal": 158.50,
  "billTradeNo": "BL202410150001",
  "operatorId": 100,
  "operatorName": "张三"
}
```

**返回示例（成功）：**
```json
{
  "code": 0,
  "msg": "记录成功",
  "recordId": 123
}
```

**返回示例（失败）：**
```json
{
  "code": 500,
  "msg": "记录失败：纸张不足",
  "recordId": null
}
```

**系统自动执行：**
1. ✅ 保存打印记录到数据库
2. ✅ 扣减设备纸张数量（-1张）
3. ✅ 检查是否触发提醒（低/中/高/紧急）
4. ✅ 发送微信模板消息（如需要）

### **Java示例（推荐）**

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;

public class PrintRecorder {
    
    private static final String API_URL = "http://yourdomain.com/nongxinle/api/machine/print/record";
    
    // 从配置读取
    private int marketId = 1;
    private int deviceId = 1;
    
    /**
     * 记录打印
     * @param billId 单据ID
     * @param distributerId 配送商ID
     * @param billTotal 单据金额
     * @param billTradeNo 单据流水号
     * @return 是否成功
     */
    public boolean recordPrint(int billId, int distributerId, double billTotal, String billTradeNo) {
        try {
            // 构建请求参数
            String params = String.format(
                "billId=%d&deviceId=%d&marketId=%d&distributerId=%d&billTotal=%.2f&billTradeNo=%s",
                billId, deviceId, marketId, distributerId, billTotal, 
                URLEncoder.encode(billTradeNo, "UTF-8")
            );
            
            // 发送POST请求
            URL url = new URL(API_URL);
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setRequestMethod("POST");
            conn.setRequestProperty("Content-Type", "application/x-www-form-urlencoded");
            conn.setDoOutput(true);
            
            // 写入参数
            OutputStream os = conn.getOutputStream();
            os.write(params.getBytes(StandardCharsets.UTF_8));
            os.flush();
            os.close();
            
            // 读取响应
            int responseCode = conn.getResponseCode();
            if (responseCode == 200) {
                BufferedReader br = new BufferedReader(
                    new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8)
                );
                StringBuilder response = new StringBuilder();
                String line;
                while ((line = br.readLine()) != null) {
                    response.append(line);
                }
                br.close();
                
                // 解析JSON（这里简化处理，实际可用JSON库）
                String json = response.toString();
                System.out.println("记录打印响应: " + json);
                
                // 判断是否成功
                return json.contains("\"code\":0");
            } else {
                System.err.println("HTTP错误: " + responseCode);
                return false;
            }
            
        } catch (Exception e) {
            System.err.println("记录打印失败: " + e.getMessage());
            e.printStackTrace();
            return false;
        }
    }
    
    /**
     * 打印票据（您的原有逻辑）
     */
    public void printBill(int billId, int distributerId, String content, double billTotal, String billTradeNo) {
        // 1. 执行打印（您的原有代码）
        boolean printSuccess = executePrint(content);
        
        // 2. 打印成功后，记录打印信息
        if (printSuccess) {
            boolean recordSuccess = recordPrint(billId, distributerId, billTotal, billTradeNo);
            if (recordSuccess) {
                System.out.println("打印记录已保存");
            } else {
                System.err.println("打印记录保存失败");
            }
        }
    }
    
    /**
     * 您的原有打印逻辑
     */
    private boolean executePrint(String content) {
        // TODO: 您的打印代码
        System.out.println("正在打印: " + content);
        return true;
    }
}
```

## ⚠️ 注意事项

### **1. 设备选择优先级** ⭐

**建议策略：**
```
1. 优先使用缓存的设备ID
2. 如果缓存无效，提示用户重新选择
3. 如果设备离线/缺纸，提示切换设备
4. 支持手动切换设备
```

---

### **2. 纸张不足处理**

**当接口返回"纸张不足"时：**
```
1. 停止打印
2. 提示用户：设备纸张不足，请加纸或更换设备
3. 允许用户重新选择设备
4. 记录失败日志
```

---

### **3. 网络异常处理**

**建议处理方式：**
```java
// 设置重试机制
int maxRetries = 3;
for (int i = 0; i < maxRetries; i++) {
    try {
        boolean success = recordPrint(...);
        if (success) {
            break;
        }
    } catch (Exception e) {
        if (i == maxRetries - 1) {
            // 最后一次失败，记录本地日志
            logToFile("打印记录失败: " + e.getMessage());
        }
        Thread.sleep(1000); // 等待1秒后重试
    }
}
```

---

### **4. 离线模式支持（可选）**

如果需要支持离线打印，可以：
```
1. 打印时，先保存到本地队列
2. 异步调用记录接口
3. 如果接口失败，保持在队列中
4. 定时任务定期重试队列中的记录
```
